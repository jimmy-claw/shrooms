## Show HN

**Title:** Show HN: Shrooms – a mesh VPN for your own devices with no coordination server

> Shrooms puts your laptop, phone, home server and a VPS on one private IPv6
> network, like Tailscale, but nobody runs a coordination server. Devices find
> each other through encrypted announcements on a public gossip network (Logos
> Delivery), then talk directly over userspace WireGuard. Addresses are derived
> from keys, so nothing hands them out.
>
> Membership is an admin-signed credential that lasts 30 days and can be
> revoked; the admin key can live on a Keycard. The Android app is a full peer
> (same Go core as the daemon), and there is a desktop app for Logos Basecamp.
>
> What it is not: anonymous (a relay sees your IP), audited (never
> independently), or relay-free (two peers behind hostile NAT go through a
> reachable member you run). The page "What it is not" is longer than the
> feature list on purpose. If you want the same idea with more platforms today,
> nostr-vpn is further along, and we compare the two honestly.
>
> Quick start (5 min, Linux + Android): https://shrooms.vpavlin.xyz/start.html
>
> It also grew a second thing: Shrooms Agents, which puts the Claude Code
> sessions on your own machines on your phone, with the mesh as the only access
> control: https://shrooms.vpavlin.xyz/agents-start.html

## Short thread (X / Bluesky / Mastodon)

1. Your devices, on one network that nobody runs. 🍄
   Shrooms: laptop, phone, NAS, VPS on one private network. WireGuard between
   them, discovery over a public gossip network, no coordination server, no
   account. https://shrooms.vpavlin.xyz

2. Five minutes from nothing: one command on the laptop, one app on the phone,
   one QR between them. Then `ssh laptop.mesh` from mobile data.
   https://shrooms.vpavlin.xyz/start.html

3. Lose a phone? Credentials expire in 30 days and can be revoked — with the
   admin key on a Keycard, from the desktop app, one tap on the card.

4. And because your machines are already on one mesh: Shrooms Agents puts your
   Claude Code sessions on your phone. Approve what they want to run from
   anywhere. No cloud relay; being on your mesh is the lock.
   https://shrooms.vpavlin.xyz/agents-start.html

5. Honest bit: it is an experiment, used daily, never audited. Linux, Android
   and Basecamp only. Everything is open source:
   https://github.com/vpavlin/shrooms

## Logos community post (forum / Discord)

> **Shrooms 0.14 + Shrooms Agents 0.47 are in the public repos.**
>
> Shrooms is a mesh VPN that uses Logos Delivery for rendezvous: devices find
> each other over encrypted announcements on the fleet, then connect directly
> over WireGuard. The traffic never touches Delivery, and tunnels keep working
> when the fleet is unreachable.
>
> New in Basecamp: the Shrooms app now does everything the Android app does —
> graph, peers, services, settings, joining your first mesh — and with the
> keycard modules installed it invites, renews and revokes devices, signed on
> the card through keycard-basecamp. It also opens Shrooms Agents through
> `basecamp.apps.launch`.
>
> Install: Package Manager → Repositories → add
> `https://apps.vpavlin.xyz/basecamp/logos-repo.json`, then Shrooms (and Shrooms
> Agents). Android: F-Droid repo `https://apps.vpavlin.xyz/fdroid/repo`.
>
> Five-minute start: https://shrooms.vpavlin.xyz/start.html · desktop tour:
> https://shrooms.vpavlin.xyz/basecamp.html
>
> Feedback and issues: https://github.com/vpavlin/shrooms/issues

## Agents-only pitch (for Claude Code / agent communities)

> **Run Claude Code on your own machines, drive it from your phone.**
>
> Shrooms Agents shows every Claude Code (or pi) session on your laptop, home
> server and build box in one app: replies streamed live, permission prompts as
> notifications, files and voice notes (transcribed on your machine), usage and
> plan limits, sessions that ask each other for work over A2A, and sessions in
> rootless containers so auto-approve does not mean handing over your home
> directory.
>
> There is no relay service and no account: each machine's agent listens only on
> its private mesh address, so only your own devices can reach it. Ten minutes
> from a working Claude Code to the phone:
> https://shrooms.vpavlin.xyz/agents-start.html
